# БудДім (демо)

Демо-лендінг для вигаданої компанії з ремонту квартир. Статичний сайт без збірки: `index.html`, `css/style.css`, `js/main.js`, шрифти Geologica і Martian Mono в `fonts/` (самохостинг, OFL).

Усі назви, імена, цифри, відгуки й контакти вигадані. Сайт зробив Влад Пригонов, [pryhonov.com](https://pryhonov.com/).

Локально: `python -m http.server 5183` у цій папці.
